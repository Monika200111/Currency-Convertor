# 💱 Currency Converter - Live Exchange Rates

A real-time currency converter web app built with JavaScript. Convert between 150+ world currencies using live exchange rate API with instant calculations.

**🔗 Live Demo:** [Try Now](https://monika200111.github.io/Currency-convertor/)  
**💻 Tech Stack:** JavaScript · HTML5 · CSS3 · REST API · Async/Await

---

### ✨ Features
- **Live Exchange Rates:** Fetches real-time data from ExchangeRate-API
- **150+ Currencies:** Supports USD, EUR, INR, GBP, JPY and 150+ more
- **Instant Conversion:** Auto-calculates as you type, no reload needed
- **Swap Function:** One-click button to swap "From" and "To" currencies
- **Responsive UI:** Clean design that works on all devices
- **Error Handling:** Shows user-friendly messages if API fails

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** ExchangeRate-API for live forex data
- **Concepts Used:** Fetch API, Async/Await, Promises, JSON, DOM Manipulation
- **Deployment:** GitHub Pages
